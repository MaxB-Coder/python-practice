# python-practice

Building Python fluency deliberately, coming from a Java and JavaScript background.

I work mostly in Java, Spring and React. Rather than picking Python up by
osmosis, I'm working through it week by week — small, self-contained exercises
and tools, written by hand.

## Structure

- `week-1/` — ⟨what you covered: syntax, data structures, comprehensions?⟩
- `week-2/todo-cli/` — a command-line todo application.

## Tooling

Pre-commit hooks run on every commit — ⟨black and ruff⟩ — so formatting and linting are
enforced rather than remembered.
